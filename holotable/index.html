Note de bataille

Collez le passage de votre partie où le combat éclate : le jeu en tire les deux camps, les effectifs exacts, les noms et les caractéristiques des personnages, puis lance la bataille. Vous vérifiez tout avant de jouer.

Bac à sable

Composez votre propre bataille : la carte, les deux camps unité par unité (toutes factions mélangées si vous le voulez), qui est aux commandes, et le déploiement automatique ou à la main. Enregistrez-la dans Mes batailles pour la rejouer.

Jeu de rôle

Table du MJ

Une table libre pour accompagner vos séances : placez n'importe quel pion, y compris vos personnages, peignez le terrain, déplacez tout à la main, suivez les points de vie et lancez les dés. Les règles s'activent d'un clic si le combat doit se résoudre en jeu.
